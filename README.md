# Customer Churn Analysis Dashboard

## 📊 Project Overview

This project analyzes customer churn using customer, subscription, support ticket, and churn event data.

The project was developed using Microsoft Excel to identify important churn patterns, customer behavior, subscription performance, and support-related factors.

## 🎯 Objectives

- Analyze overall customer churn
- Identify major churn reasons
- Compare churn across industries and countries
- Analyze churn by subscription plan
- Compare trial and non-trial customers
- Analyze churn by referral source
- Analyze support ticket patterns
- Evaluate escalation and customer support performance
- Build an interactive Excel dashboard

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas
- Data Analysis
- Data Visualization
- Dashboard Design

## 📊 Dashboard Analysis

The dashboard includes:

- Churn Rate by Industry
- Churn Rate by Country
- Churn Rate by Trial Status
- Churn Rate by Subscription Plan
- Churn Rate by Referral Source
- Support Tickets by Priority
- Support Tickets by Escalation Status

## 🔍 Key Insights

- Overall customer churn rate is 22%.
- DevTools has the highest churn rate among the analyzed industries.
- Trial customers show a higher churn rate than non-trial customers.
- Enterprise customers have the highest churn rate among the three plans.
- Features is the leading churn reason.
- The analysis contains 600 churn events.
- Total refund amount is 8,652.25.
