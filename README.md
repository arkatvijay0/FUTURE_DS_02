# 📊 Customer Churn Analysis & Excel Dashboard

## 📌 Project Overview

This project is a **Customer Churn Analysis and Dashboard** developed entirely using **Microsoft Excel**.

The objective of this project is to analyze customer churn, subscription performance, revenue metrics, support-ticket activity, churn reasons, and refund information, and present the findings through a professional Excel dashboard.

The complete analysis, calculations, KPI development, data summarization, charts, and dashboard visualization were performed using **Microsoft Excel only**.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall customer churn.
- Calculate important customer and revenue KPIs.
- Identify major customer churn reasons.
- Analyze churn across different industries.
- Compare churn across countries.
- Analyze churn by subscription plan.
- Compare Trial and Non-Trial customers.
- Analyze churn by referral source.
- Analyze support tickets by priority.
- Analyze support-ticket escalation status.
- Analyze churn events and refund amounts.
- Create a professional Excel dashboard for business insights.

# 💡 Key Business Insights

Based on the Excel analysis:

- The overall customer churn rate is **22%**.
- **DevTools** has the highest displayed churn rate among the analyzed industries.
- **Germany** has the highest displayed churn rate among the analyzed countries.
- **Trial customers** show a higher churn rate than Non-Trial customers.
- Churn rates vary across subscription plans.
- The **Event** referral source has the highest displayed churn rate among the analyzed referral sources.
- **Features** is the leading churn reason with **114 churn events**.
- The highest refund amount is **1,905.90**, associated with the **Features** churn reason.
- The analysis contains **600 churn events**.
- The project contains **2,000 support tickets**.
- **95 tickets** were escalated, giving an escalation rate of approximately **5%**.
